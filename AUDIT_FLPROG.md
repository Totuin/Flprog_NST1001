# Аудит Flprog_NST1001 1.0.1

- Исходник: полный архив `libraries.zip` от 2026-11-10, библиотека `Flprog_NST1001` версии 1.0.0.
- Статус: кандидат после автономных тестов; пользовательская Arduino-компиляция ожидается.
- Правки: согласованное чтение `_raw` из ISR на AVR, volatile, быстрый тайминг с арифметикой uint32_t, исправление примера и комментарии.
- Числа коррекции температуры соответствуют NOVOSENSE datasheet Rev 1.12 §4.3; не менялись.
- Keywords: 5 строк (1 KEYWORD1, 4 KEYWORD2), TAB/дубликаты/существование API PASS.
- Риски: аппаратный счёт всех импульсов 5–11 мкс на AVR может быть недостижим; при распараллеливании между ядрами ESP32 нужна проверка модели синхронизации; аппаратный тест на реальном датчике не выполнен.
- Исходный комплект, RT_HW, FLProg_Network и сторонние библиотеки не изменялись.
